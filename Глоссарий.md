## Сети и протоколы

**ALPN** **[С]** — расширение TLS, в котором стороны договариваются о прикладном протоколе (`http/1.1`, `h2`, `h3`). → [лекция](Теория%20сети%20на%20основе%20Dynam%20—%20лекция.md)

**ARP** **[С]** — протокол сопоставления IPv4-адреса с MAC-адресом в локальной сети. В IPv6 заменён на Neighbor Discovery. → [путеводитель](Путеводитель%20по%20сетям%20—%20как%20понимать%20сеть.md)

**CIDR** **[С]** — бесклассовая адресация: запись подсети вида `192.168.0.0/24`, где число после `/` — длина префикса сети.

**DHCP** **[С]** — протокол автоматической выдачи сетевых настроек (IP, шлюз, DNS) устройствам в сети.

**DNS** **[С]** — Domain Name System: распределённая система перевода доменных имён в IP-адреса. «Телефонная книга интернета».

**DoH** **[С]** — DNS over HTTPS: DNS-запросы внутри шифрованного HTTPS-соединения. Скрывает запросы от локального наблюдателя, но не от DoH-резолвера.

**DPI** **[С]** — Deep Packet Inspection: глубокая инспекция пакетов. Анализ трафика глубже адресов и портов: протоколы, SNI, шаблоны, поведение потоков.

**eBPF** **[С]** — механизм Linux для безопасного запуска ограниченных программ внутри ядра: статистика, фильтрация, диагностика.

**FEC** **[С]** — Forward Error Correction: добавление избыточности, позволяющей восстановить потерянные данные без повторной передачи.

**IP-адрес** **[С]** — числовой адрес устройства в сети. IPv4: `203.0.113.10`; IPv6: `2001:db8:1234::10`.

**Latency (задержка)** **[С]** — время прохождения данных от отправителя к получателю.

**MTU** **[С]** — Maximum Transmission Unit: максимальный размер пакета, проходящего через участок сети без фрагментации.

**MSS** **[С]** — Maximum Segment Size: максимальная полезная нагрузка TCP-сегмента.

**NAT** **[С]** — преобразование сетевых адресов: множество устройств локальной сети выходят наружу под одним внешним IP.

**NFQUEUE** **[С]** — механизм Linux netfilter, передающий пакеты в userspace-программу для решения «пропустить / изменить / отбросить».

**pcap** **[С]** — формат захвата сетевого трафика; инструменты: `tcpdump`, Wireshark.

**QUIC** **[С]** — современный транспорт поверх UDP; основа HTTP/3. Быстрый старт, встроенное шифрование, устойчивость к смене сети.

**SNI** **[С]** — Server Name Indication: поле в TLS ClientHello с именем запрашиваемого сайта. Исторически передаётся открыто.

**TCP** **[С]** — транспорт с соединением: порядок байтов, подтверждения (`ack`), повторные передачи. Рукопожатие: `SYN → SYN-ACK → ACK`.

**TCP-реассемблирование** **[С]** — сборка TCP-сегментов обратно в единый поток байтов; ключевая способность серьёзного DPI.

**tc-netem** **[С]** — инструмент Linux для искусственного ухудшения сети в лаборатории: задержка, потери, переупорядочивание, ограничение MTU.

**TLS** **[С]** — Transport Layer Security: протокол шифрованного канала (основа HTTPS). Даёт конфиденциальность, целостность, подлинность сервера.

**UDP** **[С]** — транспорт без соединения и гарантий: быстро, но без порядка и повторной доставки. DNS, звонки, игры, QUIC.

**VLAN** **[С]** — виртуальная локальная сеть: логическое разделение одной физической сети на изолированные сегменты.

**XDP** **[С]** — eXpress Data Path: очень ранняя точка обработки входящих пакетов в Linux (до обычного стека), требует повышенных прав.

## Криптография и защита

**AEAD** **[С]** — класс шифров с аутентификацией (например, XChaCha20-Poly1305): одновременно шифрование и защита целостности.

**CSPRNG** **[С]** — криптографически стойкий генератор псевдослучайных чисел. Обязателен для ключей и nonce; `rand()` не подходит.

**ECH** **[С]** — Encrypted ClientHello: шифрование чувствительной части TLS-рукопожатия, включая SNI.

**Ed25519** **[С]** — современная схема цифровой подписи: приватный ключ подписывает, публичный проверяет.

**HMAC** **[С]** — код аутентификации сообщения на хеш-функции и общем секрете; изменение данных делает HMAC неверным.

**HPKE** **[С]** — Hybrid Public Key Encryption: гибридная схема (асимметричная + симметричная криптография); строительный блок для ECH.

**JA3 / JA4** **[С]** — форматы отпечатков TLS-клиента: версии, шифры, расширения, их порядок. Позволяют узнавать тип клиента без расшифровки.

**Kill switch** **[С]** — режим, блокирующий весь не-loopback трафик при отказе защитного канала. Опасен для удалённых машин: можно потерять SSH.

**Метаданные** **[С]** — данные о соединении, а не его содержимое: кто, кому, когда, сколько, как долго. Шифрование их не скрывает. → [модель угроз](Модель%20угроз%20и%20границы%20доверия.md)

**Мимикрия трафика** **[С]** — попытка придать потоку статистику другого приложения (видеозвонок, стрим). Совпадение средних размеров пакетов ≠ правдоподобие.

**Модель угроз** **[С]** — формализация: какие активы защищаем, от какого противника, с какими его возможностями, какой остаточный риск принимаем.

**Nonce** **[С]** — одноразовое значение; защита от повторного использования перехваченного корректного запроса.

**Padding** **[С]** — добавление пустых байтов/пакетов для сокрытия реальных размеров сообщений.

**Port knocking** **[С]** — открытие доступа после «стука» по секретной последовательности портов; уязвим к подглядыванию и повторам.

**Replay-атака** **[С]** — повторная отправка перехваченного корректного пакета; защита: nonce + метка времени + состояние сервера.

**SPA** **[С]** — Single Packet Authorization: один криптографически подписанный пакет открывает временный доступ к закрытому сервису.

**Flow shaping** **[С]** — управление размерами, скоростью и интервалами отправки пакетов для изменения профиля трафика.

**Граница доверия** **[С]** — линия, за которой данные попадают в зону чужого контроля. → [модель угроз](Модель%20угроз%20и%20границы%20доверия.md)

**Сравнение за постоянное время** **[С]** — сравнение секретов без раннего выхода, чтобы по времени выполнения нельзя было угадать, где первое несовпадение.

## Кодирование и вычисления

**Reed–Solomon** **[С]** — код коррекции ошибок над GF(2^8): из N блоков данные восстанавливаются при наличии любых K. Цена — избыточность и CPU.

**Код GF(2^8)** **[С]** — конечное поле из 256 элементов; арифметика, в которой байты можно складывать и умножать без выхода за байт.

## ИИ-агент

**PAD-модель** **[ИИ]** — описание эмоционального состояния тремя осями: Pleasure (удовольствие), Arousal (возбуждение), Dominance (доминирование). → [теория когнитивной архитектуры](Теория%20когнитивной%20архитектуры.md)

**Затухание (decay)** **[ИИ]** — экспоненциальное ослабление эмоции или активации со временем: `E(t+1) = E(t) × λ`.

**Когнитивный цикл** **[ИИ]** — повторяющаяся последовательность «восприятие → память → внимание → действие → обучение → очистка». → [10 фаз](Когнитивный%20цикл%20ИИ%20—%2010%20фаз.md)

**Кольца безопасности** **[ИИ]** — концентрические уровни защиты агента: от неотключаемых ограничений (внутри) до модерации текста (снаружи).

**Консолидация памяти** **[ИИ]** — перенос опыта из эпизодической памяти в семантическую: эпизоды → паттерны → проверенные знания.

**Рабочая память** **[ИИ]** — активный контекст текущего диалога и целей; живёт один сеанс.

**Семантическая память** **[ИИ]** — долговременные знания и факты, выведенные из эпизодов.

**Эпизодическая память** **[ИИ]** — «что случилось»: события, диалоги, их исходы и контекст.

## InfraMap

**FTTH** **[IM]** — Fiber To The Home: оптоволокно до квартиры/дома.

**Heatmap** **[IM]** — карта уровня сигнала WiFi по плану помещения; строится теоретически или по замерам.

**Link budget** **[IM]** — бюджет оптической линии: сумма потерь (волокно, сварки, коннекторы, запас) против разницы мощности передатчика и чувствительности приёмника.

**Path loss** **[IM]** — затухание сигнала с расстоянием; в помещениях модель `PL = PL₀ + 10·n·log₁₀(d) + Σ(стены)`.

**PostGIS** **[IM]** — геопространственное расширение PostgreSQL: геометрии, тайлы, запросы «что вокруг точки».

**RSSI** **[IM]** — уровень принимаемого сигнала в dBm; чем ближе к нулю, тем сильнее (`-50` отлично, `-85` плохо).

**FUP** **[IM]** — Fair Use Policy: ограничения «безлимитных» тарифов после порога трафика.
